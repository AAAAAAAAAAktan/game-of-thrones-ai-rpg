# Game of Thrones: Stark AI RPG 🐺

Это учебный проект по ИКТ, демонстрирующий разработку текстовой игры на языке Python.

## Особенности проекта
- **Сюжет:** Противостояние Дома Старков и Ланнистеров.
- **Интерактивность:** Система выборов, влияющая на ресурсы и лояльность.
- **Технологии:** Python (логика), GitHub (хранение и версионирование).
- **AI-ассистент:** Сценарий и структура кода разработаны в соавторстве с Gemini AI.

## Как запустить игру
1. Убедитесь, что у вас установлен Python (версия 3.14 или выше).
2. Скачайте файл `game.py` из этого репозитория.
3. Откройте командную строку в папке с файлом.
4. Введите команду: `python game.py`
